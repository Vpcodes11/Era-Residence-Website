# AURA Residence

An imaginary Mediterranean property brand, independently built with the user-supplied ERA Residence website as the visual reference. Original HTML, CSS and JavaScript create the home page, apartment selection, 25 individual residence pages and contact page. The visual direction closely follows the reference's typography, editorial rhythm and Mediterranean atmosphere.

Run `npm install`, then `node server.cjs` and open http://127.0.0.1:4187.

For Vercel, import this repository with the Root Directory set to the repository root (leave the field empty). The checked-in `vercel.json` selects the Other framework preset, installs dependencies with `npm ci`, runs `npm run build`, and serves `dist/`. The Node server is for local previews; Vercel serves the generated static files directly. Apartment and contact routes have their own generated `index.html` files, so direct links and refreshes work. HTML extensions are preserved for the existing `/privacy.html` route.

If the project was previously imported with different settings, use Framework Preset **Other** and clear any custom Root Directory. Push this configuration to the branch connected to Vercel, then deploy that new commit; redeploying an older commit will not include the fix.

`dist/` is the complete deployable site. `src/` contains the original implementation; run `node build-original.cjs` after editing. Sixteen original photographs were generated using the built-in imagegen tool and are saved in `dist/assets/`. No reference photographs, video, HTML, CSS or animation scripts are used in the delivered site. Matching font families load from external font providers. Apartment data is illustrative. Enquiries are demonstration-only and are not transmitted or saved.

The site supports a day/night hero, amenity tabs with keyboard navigation, a native dialog mobile menu, a native dialog enquiry form, filters and sorting, direct apartment routes, responsive layouts and reduced-motion preferences. `node qa.cjs` verifies the main journeys in Chromium.

The original animation layer in `src/motion.js` uses locally bundled GSAP and ScrollTrigger. It includes an opening aperture, masked letter entrances, pinned courtyard zoom, pointer depth, an architectural concept aperture, an interactive architectural miniature, a coastal location section in normal page flow, scroll-driven amenity scenes, an opening architecture gate, image parallax, magnetic controls and depth on cards. An original transparent bougainvillea image supplies foreground layers. Desktop has up to five pinned scenes; sections taller than the viewport stay in normal page flow so their controls remain reachable. Mobile has one shorter hero pin when the screen is tall enough. Reduced-motion preferences skip the animation layer. Run `node motion-qa.cjs` for animation and reduced-motion checks.

`src/immersive.js` adds original Three.js scenes to the courtyard, garden, architecture and rooftop. A perspective camera travels through a modeled limestone arch; image relief, separate foreground planting, animated pool reflections and day/night shaders add spatial depth. The environment uses our AI-generated photographs; this is a cinematic scene, not a complete navigable building model. One renderer moves between visible sections, stops when no scene is visible or the tab is hidden, and limits pixel density on mobile. Original images remain available when WebGL is unavailable or its context is lost. Reduced motion skips the GPU scene and releases it when enabled during a visit. Run `npm run qa:webgl` to verify geometry rendering, camera movement, scene changes, lighting, context recovery and fallback behavior in Chromium.

The AURA Atelier in `src/atelier.js` is an original, fully modeled architectural study. Rounded balcony slabs, bronze glazing, timber pergolas, trees, garden beds, furniture and animated pool water form a rotatable miniature. Drag horizontally, use arrow keys or rotation buttons, select gardens/pool/rooftop views, and move the daylight slider between 07:00 and 21:00. Sun direction, real shadows, material tones and window illumination respond to the chosen hour. Instancing renders hundreds of details with roughly twenty draw calls. The miniature shares the existing renderer. Vertical touch gestures continue to scroll the page; mobile leaves the section unpinned. Reduced motion and WebGL fallback retain the view selector with static photography. `npm run qa:atelier` checks these interactions and image repetition.

Ten additional images were created with built-in imagegen for the garden walk, facade, beach, rooftop, garden home, penthouse, pool detail, parking pavilion, materials and coastal path. Their original PNGs are in `output/imagegen/`; optimized WebPs are in `dist/assets/`. The prompt set is recorded in `image-prompts.md`. The hero image now appears only in the hero. Main home-page photography uses fourteen distinct images, with no photograph shown more than twice; apartment cards also vary by residence type.
